# DwarfVolon

App desktop (C# + Avalonia) de apoio ao Dwarf Fortress: editor de geração de mundo com presets, e em breve visão geral dos anões e um assistente de IA via DFHack.

```powershell
dotnet run --project src/DwarfVolon
```

Toda a documentação (visão, arquitetura, roadmap, planos) está em [docs/](docs/README.md).
